# KIK-Red

Modified Kik app with enhanced features.

## Features
- Unkickable in lives (kick signals dropped client-side)
- Unlimited video recording length
- Live search filter for favorites
- Auto-like command system (!like 50000 with loop)
- Hide like overlays/status texts
- Dark centered theme with proper bottom spacing
- Made by jnetai.com

## Build
This project builds via GitHub Actions. See `.github/workflows/build.yml`.
